# GeoGenViewer V0.7 — guia

Abra um GLB com o manifesto correspondente no seletor de arquivos. Selecione **Comparar** no seletor de workspace. No painel **Revisões carregadas**, use **Carregar revisão · Revisão comparada** para abrir o segundo pacote. O botão **Laboratório de revisões** carrega os dois protótipos sintéticos. Confira projeto, revisão, protótipo, escala, origem, hash e mensagens de validação.

Em **Exibição**, selecione lado a lado, sobreposição, só diferenças ou alternância. Em telas estreitas, alterne a revisão visível pelo seletor. Expanda **Cores das diferenças** para ajustar a legenda, opacidade, visibilidade e sincronização. Selecione uma peça no modelo ou uma linha da lista para localizar seu par. Use os filtros e setas para passar entre resultados. **Alinhamento e tolerância** ajusta o referencial e a tolerância na unidade do projeto.

No painel **Correspondência manual**, confirme uma sugestão ou informe os dois IDs. Para marcar uma peça como sem correspondência, preencha apenas o ID de um lado. Escolha **Marcar como substituição** para registrar a decisão junto do par. Em **Registros de inspeção**, abra o arquivo de cada revisão e confirme que os dois registros definem a mesma grandeza antes de calcular o delta.

Em **Quantitativos**, escolha revisão, escopo, agrupamento e layout. Marque linhas para destacá-las ou selecione o componente na viewport para trazer a linha à área visível. Use **Cobertura** para verificar dados ausentes. O layout **Modelo e análise** oferece indicadores por categoria, material e revisão. Abra **Análise de fabricação** para cadastrar materiais, mapear propriedades ou informar medidas e fontes por componente.

Os painéis **Exportar e restaurar** oferecem CSV, JSON e PNG conforme o workspace. Reabra os GLBs exatos antes de importar JSON. O documento de comparação conserva a orientação base/comparada e o documento de fabricação pertence a uma revisão. As cópias exportadas ficam sob controle do usuário.
